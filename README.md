# 🦖 Dino Game

A small dinosaur game built as one of my first steps into game development. This project is a chance to learn by building something interactive, experiment with game mechanics, and have some fun along the way.

## 🎮 About the Game

Inspired by the classic dinosaur runner style of game, **Dino Game** is a small project focused on simple, engaging gameplay. The goal is to build a fun experience while learning more about how games work behind the scenes.

This is an ongoing learning project, so I'll continue experimenting with new ideas, improving the gameplay, and adding features as I develop my skills.

## 🛠️ What I'm Learning

Through this project, I'm exploring the fundamentals of game development, including:

- Player movement and input handling
- Game logic and interactive gameplay
- Obstacle mechanics and collision detection
- Game states, scoring, and replayability
- Improving gameplay through testing and iteration

## 🚀 Future Improvements

Some things I'd like to explore as the project develops:

- Improving movement and gameplay mechanics
- Adding animations, sound effects, and visual polish
- Introducing a high-score system
- Making the game feel smoother and more responsive
- Experimenting with additional features and challenges

## 📚 Why I Built This

Most of my development experience so far has been focused on web development, using technologies like JavaScript, TypeScript, React, and Next.js. I'm starting to branch out into game development to expand my skills, learn new concepts, and challenge myself with different kinds of projects.

This game is a small step in that direction. It's all about learning by doing and getting better one project at a time.
